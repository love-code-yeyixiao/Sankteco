# README

你好。

使用 祈福 则意味着你需要一个程序用来在课堂上点名，而 祈福 的目标正是让你在任何时候都能轻易使用该服务。想要更高级的点名服务，请转到 [SecRandom](https://github.com/SECTL/SecRandom) 。

祈福 与其他同类型点名软件类似，它通过用户提供的名单文件获取数据以抽选。由于点名软件所需的公平性与随机性间权衡，我们将提供多种算法于你选择。随着科学技术的不断发展， 祈福 将持续推进对算法的进一步改进。

> [!WARNING]
> 
> 例如我们要产生0~9之间的随机整数，像彩票摇奖那样，把10个质地和大小相同的号码球放入摇奖器中，充分搅拌后摇出一个球，这个球上的号码就称为随机数。计算器或计算机产生的随机数是按照确定的算法产生的数，具有周期性（周期很长），它们具有类似随机数的性质。因此， **计算器或计算机产生的随机数不是真正的随机数**  ，我们称它们为 **伪随机数** 。
> 
> ——《普通高中教科书 人教版 数学 必修二》

## 如何使用？

1. 确认你的操作系统并在 [Release页面](https://github.com/CTELaboratorio/Sankteco/releases) 下载对应文件。

2. 安装/解压缩到合适的目录。

3. 运行 Sankteco 可执行文件。
